Run locally

No installation needed.

bash
git clone https://github.com/NikhilSingh7355/NikhilSingh7355.github.io.git
cd NikhilSingh7355.github.io

Then open index.html in your browser. An internet connection is needed for Three.js and the font.

Deploy on GitHub Pages
Create a public repository named NikhilSingh7355.github.io.
Add index.html and this README.md to the repository.
Go to Settings → Pages, choose Deploy from a branch, select main and / (root), then save.
The site goes live at https://nikhilsingh7355.github.io within a couple of minutes.
Customize
Content: edit the text inside the <section> blocks in index.html.
Colors: change the --b, --r, --y and --g variables at the top of the <style> tag.
Photo: replace the base64 image in the --photo variable.
3D shapes: edit the geos array in the Three.js script.
